# シナリオ送信ビューア（PCアプリ）

シナリオエディタで書き出した**閲覧用HTML**を開き、本文をクリックするだけで
**ココフォリアのチャットへ自動送信**するデスクトップアプリです（Windows / Mac）。
ブラウザ拡張は不要です。

## 使い方

1. アプリを起動し、左上の「📂 HTMLを開く」で閲覧用HTMLを選ぶ
2. 上部の欄にココフォリアの部屋URLを入れて「🌐 ブラウザ」（Enter でも可）
   - Chrome（無い場合は Edge）が**連携用**として起動し、部屋が開きます。以後、そのブラウザで開いている部屋へ送信できます
   - 連携用ブラウザは普段のブラウザとは別のプロファイルで起動します（Chrome の仕様上、普段のプロファイルとは連携できないため）。
     初回だけココフォリアにログインしてください（以後は保存されます）
   - 連携用ブラウザが起動中なら、「🌐 ブラウザ」でそのブラウザに新しいタブで部屋を開きます。
     連携用ブラウザ内で自分で部屋を開いても認識されます
   - URL欄横の「●」が緑なら連携中です
3. 「送信先」で部屋を選ぶ（「自動」は開いている部屋が1つのとき）。「⤴」でその部屋を前面に表示
4. 「🩺 確認」で、チャット欄とチャットタブが認識できているか確認
5. 閲覧用HTMLの右上「📨」で送信モードをON（📨はアプリで開いたときだけ表示されます）
6. 本文をクリック → 送信先タブに切り替えて、送信者名で発言します

- 送信モード中は、閲覧用HTMLの上部（黒いヘッダー）に送信者名・送信先タブ・接続状態が表示されます。
  「自動（本文の設定）」のときは、エディタで本文に設定した送信先を使います。
  タブの一覧には「メイン」と、ココフォリア側のチャットタブも自動で追加されます。
- 本文コピー（📋）では、送信モード中はコピーボタンが「送信」ボタンになり、項目ごとに送信先タブを選べます。
- 送信先タブ・送信者名の初期値は、エディタの「データ」→「送信先」で設定します。
  見出し・情報枠の見出し・行左の「⋮⋮」を右クリックすると、その部分の送信先を選べます。
- 送信先のタブ名は、ココフォリア側のチャットタブ名と**同じ名前**にしてください（「メイン」は先頭のタブとして扱います）。
- ココフォリアのチャットタブは、タブバーと入力欄近くのプルダウンの両方から探して切り替えます。
  自動で読み込めないタブやキャラクターは、上部の「⚙ タブ・キャラ」で手動設定すると、送信先・送信者の選択肢に表示されます。
- 本文コピー（📋）の「選択範囲を追加」は、開いているフォルダ（複数なら一番下）の中に追加されます。送信モード中は「空白を送信」になり、全角スペースを送信先タブへ送れます。
- データ・本文のNPC/エネミーのチャパレは、送信モード中に1行ずつクリックすると、そのNPC名で送信されます。
- 「コピーも残す」をONにすると、送信した文章をクリップボードにも残します。

## 注意

- ココフォリアの画面構成が変わると、送信がうまく動かなくなる場合があります。
  その場合は「🩺 接続確認」の結果を添えてご連絡ください（`ccfolia.js` を調整します）。
- 自動送信ツールの利用は、ココフォリアの利用規約の範囲内でお使いください。

## インストールとアップデート

- 配布ページ：https://github.com/8i10/scenarioeditor/releases/latest
  - Windows：`scenario-sender-<バージョン>-win-x64.exe`
  - Mac：`scenario-sender-<バージョン>-mac-*.dmg`
- **Windows**：起動時に新しいバージョンを自動で確認・ダウンロードし、「再起動して更新」で更新されます（削除・再インストールは不要）。
  上部の「v0.x.x」ボタン、またはメニュー「ヘルプ」→「アップデートを確認」で手動確認もできます。
- **Mac**：署名なしアプリのため自動置き換えはできません。新しいバージョンがあると通知が出るので、ダウンロードしたアプリで上書きしてください（設定・ログイン状態は残ります）。

## インストーラーの作り方

`desktop/package.json` の `version` を上げてプッシュすると、GitHub Actions（`.github/workflows/desktop-build.yml`）が
Windows 版（.exe）/ Mac 版（.dmg）をビルドし、`v<バージョン>` のリリースとして公開します（アプリはこのリリースからアップデートします）。

- 署名していないため、初回起動時に警告が出ます。
  - Windows：「WindowsによってPCが保護されました」→「詳細情報」→「実行」
  - Mac：アプリを右クリック →「開く」

手元でビルドする場合：

```sh
cd desktop
npm install
npm start           # 開発起動
npm run dist:win    # Windows インストーラー
npm run dist:mac    # Mac（Mac上で実行）
```
