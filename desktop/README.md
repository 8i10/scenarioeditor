# シナリオ送信ビューア（PCアプリ）

シナリオエディタで書き出した**閲覧用HTML**を開き、本文をクリックするだけで
**ココフォリアのチャットへ自動送信**するデスクトップアプリです（Windows / Mac）。
ブラウザ拡張は不要です。

## 使い方

1. アプリを起動し、左上の「📂 HTMLを開く」で閲覧用HTMLを選ぶ
2. 上部の欄にココフォリアの部屋URLを入れて「部屋を開く」
   - 右側にココフォリアが開きます。初回はここでログインしてください（ログイン状態は保存されます）
3. 「🩺 接続確認」で、チャット欄とチャットタブが認識できているか確認
4. 閲覧用HTMLの右上「📨」で送信モードをON
5. 本文をクリック → 送信先タブに切り替えて、送信者名で発言します

- 送信先タブ・送信者名は、エディタの「データ」→「送信先」で設定します。
  見出し・情報枠の見出し・行左の「⋮⋮」を右クリックすると、その部分の送信先を選べます。
- 送信先のタブ名は、ココフォリア側のチャットタブ名と**同じ名前**にしてください。
- 「◀ ▶」で左右の幅を調整できます。
- 「クリップボードにも残す」をONにすると、送信した文章をクリップボードにも残します。
- 同じ閲覧用HTMLはブラウザで開くと「クリックでコピー」として動作します。

## 注意

- ココフォリアの画面構成が変わると、送信がうまく動かなくなる場合があります。
  その場合は「🩺 接続確認」の結果を添えてご連絡ください（`ccfolia.js` を調整します）。
- 自動送信ツールの利用は、ココフォリアの利用規約の範囲内でお使いください。

## インストーラーの作り方

GitHub Actions（`.github/workflows/desktop-build.yml`）で自動ビルドされます。
Actions の実行結果ページの「Artifacts」から Windows 版（.exe）/ Mac 版（.dmg）をダウンロードできます。

- 署名していないため、初回起動時に警告が出ます。
  - Windows：「WindowsによってPCが保護されました」→「詳細情報」→「実行」
  - Mac：アプリを右クリック →「開く」

手元でビルドする場合：

```sh
cd desktop
npm install
npm start           # 開発起動
npm run dist:win    # Windows インストーラー
npm run dist:mac    # Mac（Mac上で実行）
```
